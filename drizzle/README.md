Generated by `drizzle-kit generate`, applied in `meta/_journal.json` order. Files that are listed in the journal are history: never edit them.

**Never re-run a migration file by hand.** Some headers say otherwise:

- 0040 says it is "safe to re-run";
- 0041 says it is "idempotent - safe to run again, and after deploy as a reconciliation";
- 0042 says it is "safe to re-run".

Those comments are superseded:

- Re-running 0041 consumes allowance that was correctly returned.
- Re-running 0042 outside a single transaction briefly removes its trigger.
